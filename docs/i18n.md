# Internationalisation

Every string the editor renders comes from a message catalog. Pass `messages` to translate or reword any of them; whatever you leave out stays in English.

```tsx
<PromQLInput
  locale="es"
  messages={{
    suggestionsLabel: 'Sugerencias',
    suggestionsAvailable: (n) => `${n} sugerencias disponibles`,
    noMatches: 'Sin resultados',
    loading: 'Cargando…',
    loadError: 'No se pudieron cargar las sugerencias.',
    resultCount: (n) => `${n} resultados`,
    hintNavigate: 'navegar',
    hintInsert: 'insertar',
    hintClose: 'cerrar',
    validQuery: 'Consulta válida',
    showMore: (n) => `Mostrar ${n} más`,
    position: (line, column) => `Línea ${line}, columna ${column}`,
    kindLabels: { function: 'función', metric: 'métrica', label: 'etiqueta', value: 'valor' },
    diagnostic: (d) => translations[d.code],
    quickFix: (fix) => fixTranslations[fix.label],
  }}
/>
```

`locale` is set as the `lang` attribute on the editor's root element so screen readers use the right pronunciation.

## The catalog

| Key | Type | Used for |
|---|---|---|
| `suggestionsLabel` | `string` | Accessible name of the suggestion list |
| `suggestionsAvailable` | `(count) => string` | Screen-reader announcement |
| `noMatches`, `loading`, `loadError` | `string` | Popup states |
| `resultCount` | `(count) => string` | Popup footer |
| `hintNavigate`, `hintInsert`, `hintClose` | `string` | Popup footer key hints |
| `kindLabels` | `Partial<Record<kind, string>>` | Suggestion kinds: `function`, `aggregation`, `operator`, `keyword`, `duration`, `label`, `metric`, `value`, `term`, `custom` |
| `validQuery` | `string` | Tooltip of the valid indicator |
| `showMore` | `(count) => string` | "Show N more" under the diagnostics |
| `position` | `(line, column) => string` | Tooltip on a diagnostic's position |
| `diagnostic` | `(diagnostic) => string \| undefined` | Text for a diagnostic. Return `undefined` to keep the English message. |
| `quickFix` | `(fix) => string \| undefined` | Label of a quick-fix button |

`defaultMessages` (exported) holds the English defaults if you want to build a full catalog from it.

## Translating diagnostics

Branch on the stable `code`, not on the English text:

```ts
const es: Record<string, (d: Diagnostic) => string> = {
  PQ_UNCLOSED_BRACKET: () => 'Falta cerrar un paréntesis o corchete.',
  PQ_WRONG_ARG_TYPE: () => 'Esta función necesita un vector de rango, por ejemplo métrica[5m].',
  PQ_UNKNOWN_FUNCTION: (d) => `Función desconocida.${d.suggestion ? ' ' + d.suggestion : ''}`,
};

<PromQLInput messages={{ diagnostic: (d) => es[d.code]?.(d) }} />;
```

The full list of codes is in [Diagnostic codes](./diagnostic-codes.md).

PromQL itself is never localised: durations are always `5m`, numbers always use `.`, and the formatter's output is the same in every locale.
